# Note：思考块默认折叠为单行摘要

状态：已实施

## 问题

对话面板和回复条里的思考块在流式阶段始终展开，长思维链会把答案推得很远，用户只能一直看着滚动的思考正文；思考结束后又只剩「已思考 N 秒」，看不到这轮思路的概括。参考 DeepSeek 的 Think 行，用户希望默认只保留一行滚动摘要，点开后再看完整思考内容。

## 涉及范围

- 代码/模块：`packages/ui/src/components/chat/ThinkingReasoning.tsx`、`packages/ui/src/components/chat/ThinkingReasoning.module.css`、`packages/ui/src/components/chat/TextResponse.module.css`、`packages/ui/test/ThinkingReasoning.test.tsx`、`packages/ui/test/ReplyBarWindowApp.test.tsx`。
- UI 表面：AI 对话面板与回复条展开面板中的思考块；消息正文、操作条、外层滚动和内容指纹不变。
- 相关 Note：[修正回复条思考流的空白与错误定位](../bug-fix/2026-10-13-reply-thinking-gap.md)、[回复条悬浮展开实时对话](2026-10-12-reply-bar-hover-conversation.md)。

## 决定

- 思考块挂载即折叠，流式与完成态都不自动展开；点击整行在展开/收起间切换。
- 折叠态显示状态文案（流式「思考中…」、完成「已思考 N 秒」）；流式中另加一行摘要取最新一行并横向滚到行尾，完成后只保留时长标题，不再展示摘要。
- 正文只在展开时挂载，按既有句读切句逐句显现；展开后使用自然高度参与外层 `MessageStream` 滚动，不再限高 180px、不再创建内部滚动层或上下遮罩。
- 折叠态为右箭头，展开后顺时针转向下，收起与展开方向固定一致。

## 影响表面

- 思考阶段不再占据大段对话高度，答案和后续消息更早可见。
- 回答正文字号同步由 14px/21px 收紧到 13px/19px，标题、列表、代码块和表格各降一档，与折叠后的紧凑对话密度一致。
- 想看完整思路需要主动点开思考行；完成后只显示「已思考 N 秒」和右箭头，需要展开才能看到内容。
- 移除了完成态思考块的 180px 封顶与内部滚动；展开长思考时整段自然撑高，由外层消息流滚动，取代 [修正回复条思考流的空白与错误定位](../bug-fix/2026-10-13-reply-thinking-gap.md) 中「展开时保留封顶滚动」的行为。

## 曾考虑的替代方案

- **流式阶段继续自动展开，仅完成后折叠：** 舍弃。用户明确要求默认不展开，且流式期间正是长思考最占空间的时候。
- **保留折叠态完整正文挂载，用透明度隐藏：** 舍弃。长思维链在每条历史消息里都要保留 DOM，展开动效收益有限，还会让摘要与隐藏正文出现重复文本。
- **保留 180px 内部封顶滚动：** 舍弃。与 DeepSeek 的自然高度展开不一致，并且重新引入本次要避免的内层滚动职责。
- **摘要按句读切分取第一句：** 舍弃。DeepSeek 以换行为界；按句读切分会把没有换行的连续思考整段截成第一句，信息量不稳定。
- **完成后保留首行摘要：** 舍弃。用户要求对话结束后只保留「已思考 N 秒」标题，摘要仅在流式期间出现，避免完成态仍有一行易被误读为正文的文字。

## 后果与防回退

- 折叠态在流式中只保留摘要一行，完成后只保留时长标题；不要在流式阶段恢复自动展开或再次挂载正文。
- 摘要跟随只改 `scrollLeft`，不要用 `translateX` 或额外滚动容器，避免与面板整体滚动互相干扰。
- 展开正文继续使用外层滚动；不要重新引入 `trViewport` 式内部滚动、高度封顶或遮罩。
- 折叠/展开图标固定为右箭头→向下，不要再改回上下箭头旋转。
- 摘要取行逻辑以 `\n` 为界；新增分段展示需求时同步调整 `latestLine`，不要另写一套切分。

## 验证

- `packages/ui/test/ThinkingReasoning.test.tsx`：默认折叠、只显示最新一行、点击展开渲染完整正文、完成后摘要消失并保留带秒数的标题。
- `packages/ui/test/ReplyBarWindowApp.test.tsx`：思考流式期间保持 `aria-expanded="false"`，摘要随最新 delta 更新且不挂载正文；完成后折叠态不含思考文字，展开后可查看思考内容。
- 待实机验证：对话面板与回复条里长思考的摘要跟随手感、展开后的外层滚动位置，以及浅色/深色/隐身模式下的摘要对比度。
