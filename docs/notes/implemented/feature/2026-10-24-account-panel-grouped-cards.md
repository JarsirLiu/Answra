# Note：账户页改版为分组卡版式

状态：已实施

## 问题

用户反馈账户页「布局、样式、字体都不协调」，整体观感差。[卡片版式 Note](2026-10-24-account-panel-card-layout.md) 落地后遗留的具体问题：

1. **卡片立不起来**：卡底 `--field` 是 5% 灰，在 #F2F2F7 面板底上只差约一档明度，又无描边无投影，整页发灰发糊，看起来"没有设计"。
2. **主数值没着落**：「50 积分」孤悬在「额度」标签与用量轨之间；身份行/数值同为 12px/500 一档字重，明细行又掉到 10px，层级拉不开。
3. **退出登录形态尴尬**：全宽、左对齐、32px 高的红色 quiet 按钮悬在卡片外，既不像按钮也不像列表行。
4. **尺寸散**：按钮高 32 与全局控件档 `--ctl-h` 26 不齐，头像 28px 存在感弱，徽章贴邮箱右侧会被长邮箱挤压。

二轮实机反馈（分组卡首版上线后）：用户否决灰底卡片——「背景颜色不好看，我不想要这种背景色」。实机截图中三张 `--field-raised` 灰卡在浅色面板上发灰发脏，卡片表面改为纸面（见决定 2）；三轮再嫌纸面白得太实（「这个白色，可以再淡一些」），降为半档卡面；四轮对半档仍嫌「背景白色有点深」，要求更和谐——像素取样实测半档 #F7F7FA 对面板 #F2F2F7 仍有 5 个色阶白差，而面板↔纸面整带只有 9 个色阶，继续调比例只剩 2~3 个色阶、大面积上不可分辨，故取消卡面填充、改为无填充描边卡（见决定 2）。本 Note 已按最终形态修订。

不可违背的既有约束：不放大数字；薄荷绿只给主操作与开关；徽章中性灰阶药丸；头像固定 SVG 不拼首字母；账户面板变体禁止 vh 基准高度上限（塌缩复盘见 [vh 上限塌缩缺陷](../bug-fix/2026-10-24-account-panel-vh-max-height-collapse.md)）。

## 涉及范围

- 代码：`packages/ui/src/styles/tokens.css`（首版 `--field-raised`、三轮 `--panel-raised` 两个过渡令牌均已移除，不留死令牌）；`packages/ui/src/tokens.ts`（新增图标尺寸 `ICON_LG`）；`packages/ui/src/components/panels/AccountPanel.css`（重写）；`packages/ui/src/components/panels/AccountPanel.tsx`（结构调整）；`packages/ui/test/SettingsPanelTabs.test.tsx`、`packages/ui/test/FloatingBarApp.test.tsx`（补「可用积分」断言）。
- UI 表面：仅设置面板「账户」tab 的版式、文案与间距；设置/公告 tab 未动。
- 相关 Note：[账户页卡片版式](2026-10-24-account-panel-card-layout.md)、[档位徽章](2026-10-24-settings-account-plan-badge.md)、[统一额度展示](2026-10-23-unified-user-quota-display.md)。

## 决定

1. **分组卡版式定型**：分组标题放在卡片外（`--font-xs`、弱色，右侧可挂补充信息如「剩余 42 天」），信息行装进圆角卡（10px 圆角），发丝线只出现在卡内行与行之间。
2. **卡片为无填充描边卡：1px `--edge-line` 轮廓 + 卡内行间 `--glass-line-soft` 发丝线**：灰底（一轮）、纸面整档（二轮）、面板与纸面半档（三轮，浅色实测 #F7F7FA）相继被否后，面板↔纸面 9 色阶调节带已耗尽（见问题节四轮），卡面填充整体取消——卡片与面板同底色，分组边界完全交给描边。描边用控件档 `--edge-line`（浅色 16% 灰，与输入框同档）而非结构线 `--glass-line-soft`（8%）：无填充后轮廓是唯一分组边界，需要重一档；且变色龙只把结构线归零、控件描边保留，分组轮廓不消失，卡片也不再引入与背景不同的色块，比填充更贴合变色龙「表面融底」的约定。
3. **资料卡**：头像 28→36px 圆标（`--field-strong` 底），图标新增 `ICON_LG = 17`；徽章从「贴邮箱右侧」改为贴卡片行尾（`margin-left: auto`），长邮箱截断不再挤压徽章。
4. **额度卡**：可用积分成为主行（标签左、数值右，数值仍 `--font-md` 不放大），取代孤悬数值行；用量轨去掉描边、槽色改 `--field-strong`；明细行 10px→`--font-sm`、行高统一 36px。
5. **退出登录**：独占一张卡、居中警示色行（hover 淡警示底保留）；按钮 `border-radius: inherit` + 卡片 `overflow: hidden` 裁出圆角。登录主按钮高度 32→36 与行高对齐。
6. **间距节奏统一**：页内边距 12、卡间距 12、组标题与卡 6，行高统一 36。

## 影响表面

- 账户 tab 新增「可用积分」文案；「剩余 N 天」从卡内标题行移到组标题行右侧。
- 结构变化：额度区块外包一层 `.account-section`（标题行 + 卡片）；退出登录按钮外包一层 `.account-card`。
- 数据来源与 IPC 契约不变；设置/公告 tab 视觉不变；面板 fit-content 高度行为不变。

## 曾考虑的替代方案

- **灰底填充卡（`--field` / 首版 `--field-raised`）**：实机截图中三张灰卡在浅色面板上像「脏灰块」，用户直接否决；除非未来整体调深面板底色，账户卡不再回到灰填充。
- **纸面整档 `--paper` 卡面（二轮实现）**：灰底解决后白卡太亮，用户嫌「白得太实」；大面积卡与控制件（开关拇指、弹层）对纸面档位的需求分叉，`--paper` 保留给控制件，卡片先降半档、四轮后连填充一起取消。
- **半档比例继续微调（如七分面板三分纸面）**：面板↔纸面整带只有 9 个色阶，半档已用掉一半，再往面板靠只剩 2~3 个色阶，大面积上肉眼不可分辨，等于不改，弃用（四轮决策依据）。
- **保留填充、只加重描边**：色块本身是被否的对象，描边加重改变不了「面板上浮着白块」的观感，弃用。
- **全局把 `--field` 从 5% 提到 7%**：一次解决发灰，但会同时改变设置输入框、模型来源分段轨、对话卡表面，影响面远超账户页，弃用。
- **在 AccountPanel.css 里用 color-mix 从 `--field` 派生更深的表面**：绕开「层3 组件只消费感知令牌」的分层约定，且对 alpha 的 color-mix 插值方向不直观，弃用。
- **徽章放到邮箱下方独占一行**：[档位徽章 Note](2026-10-24-settings-account-plan-badge.md) 已因用户反馈否决，维持与身份同行。
- **退出登录用 danger 实底大按钮**：既有决定已否决（警示色块过重），弃用。
- **把设置/公告 tab 一并统一成分组卡**：能根治「同一面板两套分段语言」的割裂感，但超出本次范围（用户当前只要求账户页），留作后续独立变更。

## 后果与防回退

- 约束一：账户页卡片为无填充描边卡（1px `--edge-line` 轮廓 + 卡内行间 `--glass-line-soft` 发丝线），不得重新引入任何卡面填充——`--field` 系灰底、`--paper` 纸面、color-mix 半档白底均被实机反馈否决；也不得在组件里写色值字面量。卡内嵌套元素（头像圆标、用量轨槽）用 `--field-strong`。
- 约束二：账户页字号只走四档令牌（`themeCss.test.ts` 字号守卫覆盖 `AccountPanel.css`），不放大数字。
- 约束三：`content-panel--account` 保持 auto 高、禁止挂 vh 基准高度上限（[塌缩缺陷](../bug-fix/2026-10-24-account-panel-vh-max-height-collapse.md) 约束继续有效）。
- 「无填充描边卡 + 行间发丝线」是账户页定稿配方：后续其它面板引入分组卡（如设置 tab 统一版式）默认复用这一组合；若新页面实机验证后确实需要填充档位，再单独评估，不要预先派生新表面令牌。

## 验证

- `pnpm verify`（biome + 全包 typecheck + vitest + 架构守护）通过：ui 35 文件/261 例、desktop 45 文件/284 例全绿。`markdownEditorPane` 一例曾在全量并发下 5s 超时，单独重跑 467ms 通过，判定为负载抖动，非本次改动引入。
- `SettingsPanelTabs.test.tsx` 与 `FloatingBarApp.test.tsx` 补「可用积分」主行断言；`themeCss.test.ts` 字号守卫覆盖新 CSS（无 px 字面量），令牌完整性守卫覆盖卡片 CSS 的令牌引用。
- 两个账户页文件曾为 CRLF 行尾，biome 归一化为 LF（与仓库 `eol=lf` 属性一致）。
- 二轮（纸面卡）：用户实机截图否决灰底后，卡片表面换 `--paper` + `--glass-line-soft` 发丝线并删除 `--field-raised`，`pnpm verify` 重新全绿（结果同上）。
- 三轮（半档卡面）：用户嫌纸面白得太实，新增 `--panel-raised`（面板与纸面 color-mix 正中档）作为卡面，`pnpm verify` 重新全绿。
- 四轮（无填充描边卡）：像素取样确认用户截图为半档状态（卡 #F7F7FA / 面板 #F2F2F7）后取消填充，卡片描边换 `--edge-line`，`--panel-raised` 令牌删除，`pnpm verify` 重新全绿（结果同上）。
- 待实机验证：打开「设置 → 账户」核对无填充描边卡的分组层次、徽章行尾、退出登录卡与深浅主题/变色龙切换效果。
